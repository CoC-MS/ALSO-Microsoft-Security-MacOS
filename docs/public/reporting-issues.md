# 🐛 Reporting issues

[Documentation index](README.md)

Use the [Issues tab](https://github.com/CoC-MS/ALSO-Microsoft-Security-MacOS/issues) to report a problem with this repository's macOS exports or documentation. Search existing issues first and select the issue form that best fits the report.

Include the affected collection and filename or policy name, relevant macOS version and enrollment context, import steps, and expected versus actual behavior. Remove or redact environment-specific information.

> [!IMPORTANT]
> Public issues are visible to everyone. Do not attach tenant exports, credentials, tokens, certificates or private keys, customer details, tenant or device identifiers, assignments, or unredacted logs and screenshots.

Do not report exploitable vulnerabilities or sensitive security details in a public issue. Check the repository's [Security tab](https://github.com/CoC-MS/ALSO-Microsoft-Security-MacOS/security) for an available private reporting channel.
